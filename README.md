# Vky

Personal website of Muhammad Waqar Shahid (Waqar Shahid, M. Waqar Shahid, Vky), built with React and SCSS.

Live site: [https://waqarshahid.vercel.app/](https://waqarshahid.vercel.app/)

## Run locally

Clone the repo and open the project directory.

```
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

Tests: `npm test`

## Deploy

The site is deployed on [Vercel](https://vercel.com/). Import this Git repository. Create React App is detected automatically, so the root directory and build command can stay on the defaults.

After a production deploy, request indexing in Google Search Console. See SEO below.

## SEO

The canonical URL is `https://waqarshahid.vercel.app/`. The site includes meta tags, Open Graph, Twitter Cards, JSON-LD (`Person`, `ProfilePage`, `WebSite`, and the personal apps), `robots.txt`, and `sitemap.xml`.

Name variants in the page and structured data: Waqar Shahid, M Waqar Shahid, M. Waqar Shahid, Muhammad Waqar Shahid, and Vky.

Google Search Console is already verified. After a deploy:

1. Open URL Inspection for `https://waqarshahid.vercel.app/` and request indexing.
2. Leave the submitted sitemap at `https://waqarshahid.vercel.app/sitemap.xml`. Google reads the updated `lastmod` on its next fetch.

No new Search Console property is required unless a custom domain is added later. If a custom domain is added, point the canonical URL, `robots.txt`, and `sitemap.xml` at that domain and add the domain as a property.
